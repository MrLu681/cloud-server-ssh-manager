cloud-server-ssh-manager

A secure, beginner-friendly Python tool for automating multi-cloud server SSH login and management.

Features:
- Password and SSH key login (encrypted keys supported)
- Host key verification (SHA256 fingerprint confirmation)
- Bilingual prompts (English / 中文)
- Beginner-friendly error messages
- No plaintext passwords or passphrases

Requirements:
- Python 3.10+
- paramiko>=5

Install:
pip install "paramiko>=5"

Run:
python ssh_login_manager.py

中文说明

一个用 Python 编写的、面向初学者的安全 SSH 登录助手。

功能特性：
- 支持密码和 SSH 私钥登录（含加密私钥）
- 主机密钥验证（展示 SHA256 指纹并要求确认）
- 中英双语提示
- 新手友好的报错信息
- 不泄漏密码和私钥口令

环境要求：
- Python 3.10+
- paramiko>=5

安装：
